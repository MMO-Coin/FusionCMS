MMOCoin Donation Module 1.1.0

Accept MMOCoin through Solana Pay transfer links. Funds go to your merchant wallet. The website does not need a wallet private key or a connection to the payer's wallet.

Install or upgrade

For a fresh module installation, enable donate_mmo and run sql/install.sql against the website database. Configure it before opening donations.

For an existing module 1.0 installation, back up the database, pause donations, check for duplicate payment signatures and run sql/upgrade_1_1.sql. Legacy pending invoices are marked failed; completed history is preserved. Reconcile payments sent to old invoices manually.

Follow the full upgrade and rollback guide. Replacing files alone is not enough.

Configure the module

Edit config/donate_mmo.php:

  • merchant_wallet: the wallet that receives the tokens.
  • mmo_coin_mint: the MMOCoin mint accepted by this site.
  • rpc_url: a trusted HTTPS Solana RPC endpoint with enough capacity for your checkout traffic.
  • exchange_rate: income tracking units per MMOCoin. Package settings determine donation points.

Only classic SPL Token payments are supported. Prices allow up to nine decimal places; points must be positive whole numbers. Grant the module's administration and package permissions to the appropriate staff groups.

How verification works

Each invoice stores its owner, payment settings and 60-minute expiry. The checkout uses authenticated POST requests with CSRF tokens to check for a finalized, successful payment. The reference, merchant, mint, payment time and net received token units must match the invoice.

A matching signature alone is not proof of payment. Invoice completion, points and income commit together. Repeated verification cannot grant points twice, and a signature cannot pay two invoices.

The module checks the five newest signatures for a reference. Payments outside that window, expired invoices and payments finalized too late need manual reconciliation. An RPC outage leaves verification pending; it does not prove the payment failed. Do not resend a payment solely because the RPC endpoint is unavailable.
